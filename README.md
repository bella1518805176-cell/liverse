# LIVERSE

北京 LIVERSE 场馆座位视野小程序。

## 项目方向

- 原生微信小程序作为主要交互入口。
- 2D 座位选择、3D 观演视角、现场实拍和位置收藏。
- 场馆尺寸、逐排逐座数据及遮挡结构，待与主办方确认后补充。

## 当前资料

- [产品设计文档](docs/product-design.md)：首版范围、页面流程、验收及待补充资料。
- `output/ui/`：现有 UI 设计方案与方向图。
- `VI/`：场馆介绍参考资料。
- `tmp/`：本地临时处理文件，不提交到 Git。

当前处于设计与资料准备阶段，尚未初始化小程序工程。
