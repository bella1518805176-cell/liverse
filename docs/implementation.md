## 实施选择

1. Three.js `0.133.1` 与 `three-platformize 1.133.3` 成对固定。最初候选微信官方包基于旧 r108，核查后替换。适配隔离在预览入口，不往真实全局对象注入浏览器补丁。此选择仍是待真机验证的候选，不是已通过的支持承诺。
2. 小程序共享 API／store 输出独立 CommonJS 文件，避免每页打包各自持有登录和收藏状态。JSON Schema 在构建期编译为静态校验器，运行时禁止动态函数生成仍可加载。
3. 当前布局几何保存为版本化 PostgreSQL JSON 清单，应用服务校验坐标、座位与区域归属；数据库已有场馆／布局／场次复合外键。正式逐座资产接入前仍需把座位等拆成设计中的关系表、补齐 CHECK 与导入校验，不能声称当前已具备完整逐座数据库约束。
4. 上传暂经 API 受限转发到私有存储，尚未实现 COS 客户端受限直传签名。媒体采用逐请求鉴权代理，避免短期签名与 CDN 配置未验证时作立即失效承诺。负载与成本需正式联调后评估。
5. 图片处理后仍需人工审核。微信异步图片与文本内容安全检测尚未接入，正式启用 UGC 前必须补齐；当前不宣称已符合生产 UGC 发布条件。
6. 正式模型缺失，渲染器只允许开发示例。真实 GLB 加载、资源摘要、缓存与校准流程尚未完成。界面不把示例几何用于正式场馆，也不从宣传资料推导尺寸或排座。
7. 账号删除提供带归属的人工工单，尚未实现自动擦除和备份清理；运营需确定期限、责任人及正式隐私文本。TOTP 恢复码、后台角色管理 UI、完整事件维护和统计埋点尚未交付。

## 本次验证

- 最终自动化结果：10 项文档校验、29 项领域／API／小程序回归测试、6 项桌面／手机浏览器端到端测试全部通过；三端 TypeScript 检查与构建通过；依赖审计未发现已知漏洞。开发版小程序文件合计约 1648 KiB，最终包体仍以微信工具统计为准。
- 现有文档测试保持运行。
- 领域测试：坐标往返、楼层命中、编号精确匹配、跨版本引用、眼高、分享、对比替换、投稿限制和正式布局示例隔离。
- 独立 PostgreSQL 集成：真实迁移、收藏去重／账号隔离、图片重新编码、待审隐私、投稿请求幂等、后台角色／CSRF、并发审核版本、有用去重、工单归属／回复、删除后媒体访问、发布不可变与凭据重用撤销。
- 小程序产物：所有注册页面齐全、跨页面共享模块、禁止动态函数环境加载、缺失正式配置构建失败。
- 上传回归：鉴权先于 multipart 解析；重复上传串行写入、单一处理任务与原图不可覆盖；官方素材受角色限制、送审幂等、按座位所属区域筛选及审计。
- 生命周期回归：多个预览页独立持有场景，隐藏销毁后可返回重建，隐藏或卸载后的异步响应不会创建失效场景；浏览器分享参数初次打开及当前页变更均能恢复位置。
- Chrome 桌面 1440×1000、手机视口：素材加载、精确查找、3D 画布像素非空、环顾画面变化、坐站姿、收藏重载、对比、空实拍、运营错误提示、登录审核及审计。
- 自动化截图保存于 `output/verification/`，是浏览器画面，不是微信开发者工具或真机截图。

## 尚需验证

真实微信 AppID／登录／合法域名、微信开发者工具 WXML 编译、iOS／主流与低配安卓 Canvas 生命周期、GPU／截图／权限及包体限制；真实场馆资产、GLB、遮挡校准；COS／HTTPS／CDN、微信内容检测与容量；TOTP 生产配置；Docker 构建、恢复演练、RPO／RTO 和备案审核。

开发服务默认仅监听 `127.0.0.1`。生产容器使用 `HOST=0.0.0.0`，由 HTTPS 网关暴露并转发 `/api/`；后台静态产物为 `dist/admin`。Docker 配置仅为部署起点，当前环境没有 Docker，尚未实际构建镜像或创建腾讯云资源。
