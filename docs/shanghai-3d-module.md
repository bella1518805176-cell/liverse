# 上海1208座3D模块

本版将网页的3D占位替换为可交互尺寸简模。座位使用[落位估算数据](../apps/demo/src/mock/shanghai-3d-placement-estimate.json)，1F 800座、2F 408座；一楼560mm椅距、900mm排距，二楼每排一阶、495mm阶高和900mm径向进深。

## 页面使用

- “3D视图”默认打开场馆总览：可旋转、滚轮/双指缩放，通过全馆、仅看1F、仅看2F检查层间关系。工具栏可放大、缩小、俯视、复位。
- 总览中点击三维椅子选择对应排座。选中高亮、底部位置、楼层和2D座位图同步；键盘方向键可改变视角，选位置浮层可精确定位。
- 选择座位后，“从这里看舞台”直接进入该椅子上方的观众视角。机位为底座中心加1.2m眼高，目标为舞台示意表演区；可拖动环顾。
- “手机取景”为同一虚拟机位提供取景框及1×/2×模拟视场角，分别为60°和32°；不是调用摄像头或现场实拍。
- 未选位置时，观众模式提供选座入口；图形渲染失败或上下文丢失时提供重试及回到2D入口。

## 几何和依据

场景为按尺寸生成的开放剖切简模，包括场地底板、舞台、曲面屏、控台、1208把椅子、12排弧形看台、两条分段小踏步通道、前栏杆及悬挂设备示意。没有直接导入原SKP完整网格。为方便检查排座，顶盖和靠近相机一侧的高墙省略；外框使用地面包围范围，不冒充建筑净轮廓。

舞台使用前20/中17/后13m、深9m、高1.5m的分段轮廓示意，未将其面积宣称为163m²。屏幕采用展开宽33.28m、高12m、底边高出1F地面2m，曲率半径15m及安装路径为暂定值。控台为3×7×1.2m占位盒。前栏杆1.05m高、灯具和人员形体均属于示意资产；悬挂设备位置参考已有组件包围盒。

二楼座位和台面遵循估算文件中的同心圆；座椅底座位于每排脚下标高并按弧线径向转向。通行台阶把每排495/900mm分成三个165/300mm小踏步。原SKP首尾平台、梁柱、孔洞和栏杆细节尚未逐件复刻。

15个二楼灰色座位及一楼后区的提示沿用座位图标记；此版不计算视线遮挡比例。坐姿眼高1.2m、屏幕曲率、舞台目标点及外观均可继续调整。页面始终显示“尺寸估算模型”，不将预览当作实测视野。

## 代码与生命周期

- `apps/demo/src/venue-data.ts`：从已提交坐标表适配座位身份、XYZ、朝向、遮挡标记和简模参数。
- `apps/demo/src/venue-scene.ts`：Three.js几何、灯光、相机、实例化座椅、遮挡感知射线拾取、指针/双指/滚轮/键盘控制和资源释放。
- `apps/demo/src/Venue3D.tsx`：画布生命周期、楼层筛选、机位模式、取景框、焦段、错误/重试和位置摘要。
- `apps/demo/src/main.tsx`：保留原2D座位数据和位置浮层，按楼层/排/号连接3D选择；模块在进入3D时才延迟加载。

椅子采用共享几何的实例化绘制，渲染按交互和尺寸变化触发，不持续空跑。退出3D会移除监听和ResizeObserver、取消待绘制帧并释放材质、纹理、几何及WebGL资源。重新加载使用新画布，避免复用失效的图形上下文。数据标记用于自动化验证，不向产品用户显示调试信息。

## 验证

构建：`pnpm build:demo`。类型检查：`pnpm typecheck`。项目回归：`pnpm test`。桌面/手机页面验证：`pnpm test:demo`。

浏览器测试从真实估算座位XYZ投影到当前相机后点击实际网格，核对选中ID、2D联动、眼高坐标、楼层800/408筛选、1208总数、焦段、空状态及上下文丢失后的重新加载。截图保存在本地`output/verification/`。这些验证在Chrome软件WebGL环境完成；并不等于已经适配微信原生小程序的图形运行时。
