# 上海1208座：第一版3D落位尺寸估算

日期：2026-11-11。此版按用户新增条件计算：**二楼一排一阶，阶高495mm、台面径向进深900mm；一楼允许结合现有资料推算。**

可以先按本方案做“模型总览＋座位落位”。座位数量/编号以目前校正后的1208布局为准；一楼采用**椅子中心距560mm、同区排中心距900mm、首排中心退舞台3m**。二楼采用模型圆弧近似与逐排495/900mm递进。所有座位已生成估算XYZ和朝向，位置不标作现场实测。

交付文件：

- [1208座估算坐标 JSON](data/shanghai-3d-placement-estimate.json)：参数、坐标系、逐排尺寸、每座XYZ/朝向/估算状态及来源。
- [1208座估算坐标 CSV](data/shanghai-1208-estimated-positions.csv)：可用于建模软件或前端导入，含网页米制坐标及原SKP坐标。
- [560mm椅距推算的CAD参考点](data/shanghai-chair-reference.json)：旧图567个重复参考点及最近邻统计。
- [等比例俯视预览](figures/shanghai-estimated-placement.svg)：一楼与二楼分开显示；SVG内可查看每个点的座位ID和估算XYZ。
- [原始尺寸与版本差异](shanghai-3d-dimensions.md)：壳体、舞台、屋面、屏幕及其他设备沿用此前分析；本估算补齐排座方案，不改写原始证据。

“椅距”在这里指**座椅中心到中心**，不是两椅之间的空隙。按宽0.52m简模，左右空隙约0.04m；按深0.60m简模和0.90m排距，同区前后外形间隙约0.30m。此处只是几何空隙，不是净疏散宽度或合规结论。

旧建筑CAD `X-01-A-100_t3.dwg` 的 `seat` 块中有567个半径65mm的重复圆形参考标记；它们的最近邻距离中位数为**559.912mm**，397/567个在550～570mm内。因此采用560mm作为试排椅距。参考标记半径不代表椅子尺寸；这些点来自旧排座图，只借用重复间距，不把旧座号和旧数量覆盖到1208新布局。

椅距可先在540～600mm、同区排距850～950mm范围内调整以查看效果。这是建模调节范围，不是统计置信区间。40座按每座560mm分配为22.4m宽；若改为600mm，则需24m宽并重新核对控台与边界。

## 2. 坐标约定

网页模型以米为单位：**X横向、Y向上、Z从舞台前沿向观众后区**。暂把舞台前沿中心定义为(0,1.5,0)，其下方一楼地面点为(0,0,0)。编号暂按图中从左到右对应X负到正递增；与现场左右称谓的对应仍可整体翻转。

与原SKP的转换保持此前候选锚点：

```text
webX = nativeY - 361.042760
webY = nativeZ - 0.600000
webZ = nativeX - 10.973863

nativeX = webZ + 10.973863
nativeY = webX + 361.042760
nativeZ = webY + 0.600000
```

座位 `position_m` 是椅子底座/落地中心，不是坐垫或眼睛的位置。椅子资产默认朝局部-Z；JSON给出绕Y轴的 `yaw_rad`。一楼统一朝舞台，yaw=0；二楼沿拟合圆弧径向朝前。

## 3. 一楼横向落位

前区40座不拆块，保持对称。设每排座号为 `n`：

```text
前区1～12排：X = (n - 20.5) × 0.56
1号中心=-10.92m；40号中心=+10.92m
首末中心跨度=39×0.56=21.84m
加两端半椅宽的实际简模外包宽=21.84+0.52=22.36m
按每座一个0.56m分配单元计总宽=22.40m
```

中后区的中央空间围绕控台保留；每侧最靠中央的座椅中心取X=±2.52m。

| 分区 | 座号块 | X中心范围m | 每侧中心跨度 | 简模每块外形宽 |
| --- | --- | --- | ---: | ---: |
| 前区1～12排 | 1～40连续 | -10.92～+10.92 | 整排21.84m | 整排22.36m |
| 中区13～19排左侧 | 1～16 | -10.92～-2.52 | 8.40m | 8.92m |
| 中区13～19排右侧 | 17～32 | +2.52～+10.92 | 8.40m | 8.92m |
| 后区20～23排左侧 | 1～12 | -8.68～-2.52 | 6.16m | 6.68m |
| 后区20～23排右侧 | 13～24 | +2.52～+8.68 | 6.16m | 6.68m |

后区暂采用与中区相同的中央边界、向外减少4座的对称落位。Excel空白列只约束分块关系，不能证明中后区实际中央宽度相同；这一点作为可调定位参数保留。

中央两侧椅子中心相距5.04m；减去半椅宽合计0.52m，**中间外形净留空4.52m**。按控台横向3m，左右各剩 `(4.52-3)/2=0.76m`。这只是试排空隙，实际设备、栏杆和通路宽度需在模型叠合时复核。

## 4. 一楼纵向落位与控台

暂把宣传册“FOH长7m、宽3m、距舞台约14m”理解为：**横向3m、纵深7m，前沿Z=14m，后沿Z=21m**。资料没有指定测距端点和长边方向，因此朝向和锚点属于估算；不能称作已确认控台坐标。高度先用1.2m占位。

为让前区、控台和后区各有明确边界，使用分区起点，而非23排无间断等距：

```text
13～19排：Z = 14.8 + (排号-13)×0.9
```

按深0.6m椅子，几何核对：

- 第12排后沿Z=13.2m，至控台前沿14m留0.8m；第13排椅前沿14.5m，与第12排椅后沿相距1.3m。
- 控台后沿21m，至第20排椅前沿22m留1m；第19排椅后沿20.5m，与第20排椅前沿相距1.5m。
- 中区7排中心跨度5.4m，加椅深0.6m，纵深外包6m，放在控台前后7m区间内，两端各留0.5m。
- 一楼椅子总体外包为 **X=-11.18～+11.18m、Z=2.7～25.3m**。原模型观众地面包围纵深29.58m，故后侧粗略余量约4.28m。

前区宽约22.4m，比宣传舞台前宽20m多约2.4m，即两侧各伸出约1.2m，尺寸上可作为初版总览的合理候选。没有为了凑800座把单座缩小到舞台宽度内。

## 5. 二楼一排一阶：全部标高

用户确认的是相邻排的台阶关系及495/900mm尺寸，**并未新增第一排绝对标高**。本方案暂沿用SKP第一主要面原生4.9m；原建筑图5.455m的版本差异仍保留，不把它解释为用户已确认。

```text
第r排脚下原生标高 = 4.900 + (r-1)×0.495
第r排网页Y = 4.300 + (r-1)×0.495
相邻排径向进深 = 0.900m
```

## 6. 二楼平面弧线与座椅分布

原SKP第三主要踏面（原生Z=5.890m）的完整弧线采样点可拟合圆形。排除通道切口和裁切端点后，用13个弧点拟合得到：

| 参数 | 候选值 |
| --- | --- |
| 原生平面弧心 | X=-25.104572，Y=361.042760m |
| 转换后的网页平面弧心 | X=0，Z=-36.078435m |
| 第3排台面外缘半径 | 54.029337m |
| 第1排台面内缘半径 | 54.029337－3×0.9 = 51.329337m |
| 每排座位中心在台面内的径向偏移 | 0.450m，暂取台面中间 |
| 拟合点最大径向残差 | 约0.000001m；仅反映理想模型采样点，不是现场测量精度 |

对第r排，中心半径为 `R=51.329337+(r-1)×0.9+0.45`。给定横向X后：

```text
Z = -36.078435 + sqrt(R²-X²)
yaw = atan2(X, Z+36.078435)
```

横向分配采用560mm投影中心距，并保留原图的左/中/右三块：

- 中区17座：X=-4.48～+4.48m，简模外包9.48m。原模型中区两条通行切口之间约9.6m，尺寸相容。
- 左区靠中央的末座中心固定X=-6.16m，座位向左扩展；右区首座中心固定X=+6.16m，向右扩展。
- 中侧区相邻端座中心相距1.68m；减去两端半椅宽合计0.52m，椅子外形间距约1.16m，可容纳模型约1m的通道切口。实际径向位置和切口边界仍需叠合。
- 最宽的第5～9排侧区外端中心X=±11.76m。第11排收窄为±8.96m，第12排为±8.40m，保留中间无座。
- 第2排保留左9/中17/右8；不为视觉对称增加一座。所有排编号沿用已校正的网页拓扑。

这里的560mm是横向投影间距。实际沿弧中心距会略大，随偏离中轴而变化；不能同时宣称每座沿弧严格560mm。正式模型可在保持端点与通道的前提下改用沿弧分配，但应同步更新座位坐标。

该圆弧方案与原模型中段相容，但不把12个原有水平面直接等同于12个标准完整台面网格：原模型首尾平台更宽，台阶和通道还有局部切口。椅子中心可据此生成，原网格接触和实际栏杆位置仍需在建模时检查。

## 7. 建模使用与校验

导入JSON/CSV后，以座位ID建立2D与3D关联。1F椅子底座放在webY=0；2F底座采用逐排脚下Y，并按yaw旋转。不得再把2D SVG的20像素或Excel空白列直接换算为米。

可以先沿用现有SKP壳体、舞台、楼板、栏杆和设备，再叠加这1208个座位中心。二楼示意台阶按每排内外半径和脚下标高生成；一楼控台是估算占位盒。15个灰色座位保留原表标记，不把它解释成已经跑过3D遮挡计算。

本次自动校验包括：数量/ID/来源一致、逐排高度和径向差、中央留空、左右分块、椅子矩形角点处于解析台面内、同层座椅外形不相交、控台不与座椅相交、1F椅子外包处于地面总体包围范围内。**尚未验证原SKP每个椅脚的接触、墙柱/栏杆碰撞、净通行宽度、视线及遮挡比例。**

重算：`node scripts/build-shanghai-placement.mjs`；同步检查：同命令加`--check`。所有估算记录带 `estimated_for_model_review` 状态，原证据数据仍保持独立。
