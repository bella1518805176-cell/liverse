# 上海 LIVERSE 首版 Demo 产品设计文档

版本：v1.0；日期：2026-11-03；状态：依据本轮确认范围编写，供页面设计、开发和验收使用。

本轮交付为产品文档，不修改现有 Demo 功能或发布线上版本。下一轮开发以本文为当前 Demo 的范围依据；旧版完整产品规划保留为历史参考。

## 1. 目标与范围

首版只验证一个完整流程：选择场馆和场次 → 查看对应楼层的真实座位号图 → 选择一个位置 → 在同一页面切换 2D／3D → 切换三种视角模式。

2D 根据上海场馆真实座位图制作。3D 本轮只提供界面、模式切换和位置状态联动，暂不生成或加载场馆模型。

### 1.1 已确认决策

| 决策 ID | 项目 | 当前规则 |
|---|---|---|
| DEC-01 | 首版场馆 | 上海 LIVERSE，图纸标题为「上海LIVERSE音宇宙艺术中心」；本次 Demo 取代之前北京示例的展示范围，其他场馆暂不制作 |
| DEC-02 | 场馆切换 | 主页面保留可用的场馆选择入口；首版列表只有上海这一项真实可用场馆，数据和交互支持以后加入场馆 |
| DEC-03 | 场次切换 | 必须可切换；未提供真实演出信息时，内置至少「演示场次 A」「演示场次 B」，明确标为演示，不伪造艺人、日期或官方演出 |
| DEC-04 | 指定布局 | 首版仅制作工作表「全坐席（有过道）1184」，两个演示场次均明确绑定此布局；不导入其他工作表为可用布局 |
| DEC-05 | 楼层规则 | 2F 为固定座位；1F 为可按场次调整的座位，数据关系必须支持场次关联不同的一楼布局 |
| DEC-06 | 单页结构 | 场馆、场次、楼层、位置、2D／3D 及三种视角均在同一探索页面完成，选择器使用浮层，不另开业务页面 |
| DEC-07 | 3D 边界 | 3D 是可进入、可切换模式的占位视图；场馆总览、观众视角、手机取景三个入口必须具备，暂不实现真实模型与相机效果 |
| DEC-08 | 其余功能 | 实拍、回忆、轨迹、我的、登录、收藏、对比、分享、投稿、票务和舞台调整等全部不进入本版 |

场馆入口首版可以选择并确认上海；由于只制作一个场馆，本版无法演示两个真实场馆之间的地图变化。不得加入虚构场馆地图来表现已完成多馆还原。场次切换则通过两条明确标注的演示记录提供实际可操作流程。

旧假设「同馆不同场次座位布局不变」不再适用于本 Demo。改为「固定的二楼座位底图 + 当前场次绑定的一楼布局」。首版两个场次使用同一布局是资料范围限制，不是场馆规则。

## 2. 资料依据与座位核对

资料来源：用户提供的 `material/上海Liverse座位分布图表.xlsx`，本版只使用工作表「全坐席（有过道）1184」。场馆及楼层固定／可变属性依据用户本轮说明。工作簿内容作为数据资料使用；原文件保持不变，座位核对结果记录于下表。

### 2.1 已读取的图纸内容

| 楼层／区域 | 图纸标注座数 | 已读取编号数 | 图纸位置与编号结构 |
|---|---:|---:|---|
| 1F 前区 | 456 | 456 | M12:AY23；1楼1排至12排，每排1至38号；中间过道位于19号与20号之间 |
| 1F 中区 | 224 | 217 | M30:AY36；1楼13排至19排，每排读取1至31号；中间为控台／留空区域 |
| 1F 后区 | 96 | 96 | Q43:AV46；1楼20排至23排，每排1至24号；标题标有「有遮挡」 |
| 2F 固定坐席 | 408 | 408 | N54:BD65 范围；2楼1排至12排，各排数量和左右起止位置不同，需逐座保留 |
| 合计 | 1184 | 1177 | 标注与现有编号相差7座，差异出现在1F中区 |

说明：表内单元格范围用于定位读取区域，范围内留空、控台和过道不代表座位。座位数量统计只计入有明确排归属的座号，不能计入区域小计、标题或其他数字。

### 2.2 数据差异的处理规则

- 图纸标注 1F 共776座，当前可读编号为769个。中区标题为224座，但7排各31号合计217个；左右小计标注为112和112，与现有编号也不完全一致。
- 保留布局原名「全坐席（有过道）1184」，不能把布局名称中的1184直接作为已还原座位数。
- 当前开发以明确读取的1177个编号为基础，缺少的7座不补号、不猜位置、不挪动过道凑总数。页面布局说明显示「图纸标注1184座，7座编号待核对」，不对外宣称已完整还原1184座。
- 开发可先推进图纸已有位置与全部交互；资料补齐前，交付应记录座位数据待核对状态。确认剩余7座或收到修订图纸后，更新布局版本并复核全量编号，才能按完整1184座验收。
- 二楼标题还包含「无遮挡393」描述，本版只按来源记录，不将其解释为已逐座验证的视野结论。没有逐座核实前，不推断具体哪15座遮挡。

### 2.3 2D 还原要求

必须保留舞台方向、前中后区、排号、座号顺序、中央与侧边留空、过道、控台和二楼各排不规则起止位置。不得用规则网格替换图纸，也不能沿用旧 Demo 的随机或示例座号。

图纸是一张座位号示意图，并非带尺寸的测量图。2D 坐标表达图上的相对位置，不据此输出真实米数、层高、视线角度或遮挡比例。两个楼层分别绘制，不能把 Excel 上下分块的排版当作现场两层的空间前后关系。

## 3. 页面结构

全产品只有一个主探索页面，无底部业务 TabBar。页面默认进入上海、演示场次 A、1F、2D、未选中位置；3D 模式初始为「场馆总览」。

```text
┌──────────────────────────────────┐
│ 上海 LIVERSE ▾   演示场次 A ▾     │
│ 全坐席（有过道）1184              │
│ [ 2D 座位图 ] [ 3D 视图 ]        │
│ [ 1F 一楼 ] [ 2F 二楼 ]          │
├──────────────────────────────────┤
│                                  │
│    2D：舞台、区域、排号、座号     │
│    或                            │
│    3D：对应模式的占位视图         │
│                                  │
│           缩放／复位（仅2D）      │
├──────────────────────────────────┤
│ 3D时：[场馆总览][观众视角][手机取景]│
│ 已选位置／尚未选择位置            │
│ [选位置／更换位置] [清除选择]     │
└──────────────────────────────────┘
```

图为信息结构示意，最终尺寸随手机屏幕及微信安全区适配。2D 时不显示三个 3D 模式按钮；3D 时不显示无效的地图缩放工具。

场馆、场次和位置选择器均为底部浮层，同一时间只打开一个。取消或关闭浮层不改变当前确认状态。浮层打开时，地图不接收穿透点击。

## 4. 必须交付的功能

以下均为本版必需能力，编号用于开发追踪和验收。

| 需求 ID | 功能 | 本版行为 |
|---|---|---|
| DFR-01 | 场馆选择 | 点击当前场馆打开列表，展示上海与选中标识，确认后回到原页面；仅展示已准备数据的场馆 |
| DFR-02 | 场次切换与布局绑定 | 至少两个演示场次可切换，显示当前场次；按场次读取一楼布局，并复用该场馆二楼固定座位数据 |
| DFR-03 | 真实2D地图与楼层 | 分别展示1F、2F，按指定工作表保留已有编号、相对分布和非座位区域；支持平移、缩放和复位 |
| DFR-04 | 单位置选择 | 点击地图中的真实座位或通过位置浮层选择楼层、排、号；高亮一个位置，显示完整楼层／区域／排／号 |
| DFR-05 | 同页2D／3D切换 | 只切换主视图区，保持当前场馆、场次、楼层和有效的选中位置；切回2D恢复地图状态 |
| DFR-06 | 三种3D视角入口 | 3D中可选择场馆总览、观众视角、手机取景，提供不同的模式标题与占位说明；不生成模型 |
| DFR-07 | 统一状态与切换规则 | 场馆、场次、楼层、位置及视角共享同一状态；上下文变化后按第7节校验选择，避免旧位置串用 |
| DFR-08 | 数据提示与异常状态 | 区分演示场次、图纸座数差异、未选择位置、布局未配置和读取失败；支持取消、重试或回到2D继续选择 |

### 4.1 场馆与场次

场馆浮层展示名称、城市、当前选中标识。首版不做城市筛选、搜索、场馆数量统计或多馆宣传页。

场次浮层只列出当前场馆的记录，显示名称、演示标识和关联布局名称。真实演出日期未提供时不填写假日期。默认选中演示场次 A，切换到 B 后顶部名称必须更新，即使两者共用布局。

切换场次不是更改文字后仍无条件沿用旧图：必须解析目标场次的布局关系。没有一楼布局时显示「该场次暂未配置一楼座位图」，不默默套用1184方案。二楼固定数据仍可查看。首版不提供用户编辑场次或拖动座椅的配置器。

### 4.2 2D 地图

- 1F 展示前区、中区、后区，保留原图相应排号及控台；2F 展示其独立固定排座图，两层始终有明确标题。
- 两层均标示舞台方向。二楼若仅有方向依据，使用方向标示，不虚构舞台与楼层的实测距离。
- 初始缩放适配当前楼层全图。支持双指缩放、拖动平移、放大／缩小和复位；拖动结束不应误选座位。
- 缩小时展示舞台、区域与排的结构，放大后展示可读座号。座位过密时提示放大，不扩大热区覆盖相邻座位。
- 座位被选中时使用品牌强调色及描边／标记，底部文字同步更新。过道、控台、标题、小计与留空均不可选。
- 后区可附「原图标注：有遮挡」，不能显示本版未验证的逐座遮挡判定。
- 复位只重置当前楼层的平移与缩放，保留有效的选中位置。

### 4.3 位置选择

同一时间最多选中一个位置，点击另一座位直接替换。位置浮层的楼层、排、号均来自当前布局数据；切换楼层／排时重置不再有效的下级选项，确认后同步地图楼层和高亮。

3D 占位视图仍可打开同一个「选位置／更换位置」浮层。若希望从地图选座，提供「回到2D选位置」操作，仍留在同一页面。不在没有模型的画面上实现虚假的3D拾取。

位置摘要示例为「上海 LIVERSE · 1F前区 · 1排1号」，该编号存在于指定图纸。摘要不显示价格、余票或锁座状态。

### 4.4 3D 占位与三种模式

切到3D后始终显示「3D模型暂未接入」；切换模式更新选中样式、标题、说明及当前位置摘要。模式可以切换，真实视角效果尚未实现。

| 模式 | 未选位置时 | 已选位置时 | 本版不实现的内容 |
|---|---|---|---|
| 场馆总览 | 展示「场馆总览」占位与选位置入口 | 保留选中位置摘要，说明未来将在总览中标记该位置 | 建模、环绕、建筑剖切和3D位置标记 |
| 观众视角 | 可以选中该模式，显示「请先选择位置」及选择入口 | 展示「观众视角」占位、对应排座及模型暂未接入说明 | 真实座位机位、视线、眼高、俯仰和遮挡模拟 |
| 手机取景 | 可以选中该模式，显示「请先选择位置」及选择入口 | 展示「手机取景」占位、对应排座和简洁取景框 | 真实相机权限、设备镜头、倍率、焦距、画质模拟、拍照和导出 |

即使没有选座，三个模式也均可点击，以便评审单页流程；缺少位置时通过引导处理，不制造一个默认座位。取景框为界面占位，不显示随机演出画面、示例建筑或假装由所选位置拍摄的图片。

## 5. 核心流程

### 5.1 从地图选择位置

进入上海演示场次 A → 默认1F座位图 → 放大并点击某个有效座位 → 底部显示排座 → 切换3D → 选择观众视角／手机取景 → 查看模式占位与原位置摘要 → 返回2D，仍能找到原选中座位。

### 5.2 从二楼选择位置

点击2F → 展示固定座位图 → 选择某个座位 → 切换3D并选择模式 → 切换演示场次 B → 同一场馆、同一固定座位版本且仍有效时，保留这个二楼位置。

### 5.3 在3D中更换位置

进入3D → 点击选位置 → 选择楼层、排、号 → 确认 → 摘要更新并继续当前3D模式；切回2D后展示新楼层、新位置及高亮。

### 5.4 切换场次

打开场次浮层 → 选择演示场次 B → 解析目标布局 → 更新顶部名称与数据 → 校验原选中位置。A／B目前共用布局，因此图形可以不变；不能为了制造差异擅自删减或移动真实座位。

## 6. 共享数据与状态

本节定义产品关系，具体接口和存储设计在后续技术方案中细化。本 Demo 可使用本地配置，不要求为此建设新的后台或数据库功能。

### 6.1 数据关系

| 对象 | 必要关系与规则 |
|---|---|
| 场馆 Venue | 拥有楼层定义和2F固定座位版本；首版仅有上海的真实数据 |
| 场次 Performance | 必须属于一个场馆，并引用一个1F布局版本；有明确演示标识 |
| 固定楼层版本 FixedFloorVersion | 属于指定场馆，提供2F座位编号与2D位置；不因不同场次重复生成座位身份 |
| 一楼布局版本 FloorLayoutVersion | 属于指定场馆，提供1F座位编号、相对位置、区域、过道和控台；不同场次可引用同版或不同版 |
| 座位 Seat | 含楼层、区域、排、号、2D位置、来源单元格及所属版本；显示编号不能单独作为全局身份 |
| 场馆模型能力 | 本版为未接入；2D位置不自动等于真实3D坐标，未来模型需单独测量和标定 |

同名座号在1F、2F或不同一楼布局中不代表同一个位置。选中位置必须绑定场馆、楼层、所属固定／可变布局版本和座位标识。

### 6.2 页面状态

| 状态 | 含义 |
|---|---|
| venueId | 当前场馆 |
| performanceId | 当前场次 |
| floorLayoutVersionId | 当前场次对应的一楼布局版本，可缺失 |
| fixedFloorVersionId | 当前场馆二楼固定版本 |
| activeFloorId | 当前显示楼层1F／2F |
| selectedPosition | 一个带完整所属关系的座位，或空值 |
| displayMode | 2D／3D |
| cameraMode | 场馆总览／观众视角／手机取景 |
| mapViewportByFloor | 当前布局上下文中每层的平移和缩放，用于切回时恢复 |

这些状态由单页共同持有。2D、位置摘要、选择浮层和3D占位不能各存一份互相独立的选座结果。首版只要求页面会话内保持状态，不做账号同步、最近浏览或跨重启恢复。

## 7. 切换与恢复规则

| 规则 ID | 操作／条件 | 选中位置处理 | 视图与其他状态 |
|---|---|---|---|
| ST-01 | 同一上下文切换2D／3D | 保留有效位置 | 保留楼层、3D模式及2D缩放平移 |
| ST-02 | 切换楼层 | 切到与所选位置不同的楼层时清空选择 | 切换到目标楼层图及其已保存视口；3D模式保留，需位置的模式显示引导 |
| ST-03 | 选择新位置 | 用新位置替换旧位置 | 同步其楼层；2D定位并高亮，3D模式保留 |
| ST-04 | 切换场次且1F版本完全相同 | 原1F位置仍存在时保留 | 更新场次名称，保留当前视图和地图状态 |
| ST-05 | 切换场次且1F版本变化或缺失 | 原1F选择清空，提示布局变化并重新选择 | 1F重新适配新图或展示布局未配置状态，不套用旧图 |
| ST-06 | 同馆切场次且2F固定版本相同 | 原2F位置仍存在时保留 | 更新场次，继续展示2F，保留当前模式 |
| ST-07 | 同馆切场次且2F固定版本变化 | 原2F选择清空，重新选择 | 更新2F图并复位对应视口，不按相同排号座号映射 |
| ST-08 | 切换不同场馆（数据扩展后的规则） | 清空所有旧位置 | 清空旧场次与视口，载入目标馆默认可用场次和楼层，回到2D及总览初始模式 |
| ST-09 | 取消浮层或重选当前场馆／场次 | 不改变原选择 | 保留原视图与已确认状态 |
| ST-10 | 当前楼层地图复位 | 保留有效位置 | 仅恢复当前楼层的适配缩放和平移 |
| ST-11 | 清除位置 | 置空 | 保留场馆、场次、楼层及当前视图／模式，显示未选择引导 |
| ST-12 | 目标数据读取失败 | 不把旧位置标成目标场次／场馆的位置 | 保留原已确认上下文并提示重试；目标数据完整后一次更新，快速切换时忽略过期结果 |

楼层切换采用清空跨层选择的简单规则，避免2F地图配着1F位置摘要；通过选位置浮层确认新座位时，则同时切换楼层和选择，不能先清空再丢失刚选中的位置。

## 8. 视觉与体验要求

沿用黑白灰与品牌橙方向，地图保证文字和座椅轮廓可辨。1F／2F、2D／3D与当前3D模式均使用文字和选中样式共同表达，不能仅靠颜色区分。

核心操作适配手机竖屏、微信顶部胶囊和底部安全区。工具与选择按钮保留足够点击面积，地图支持渐进显示编号。首次进入不要求登录；不存在广告横幅、推广码或与本版无关的入口。

3D占位立即可见，不显示无限加载、虚假百分比或无法使用的手势提示。所有提示使用明确原因，如「该场次暂未配置一楼座位图」「请先选择位置」「3D模型暂未接入」。

本次需求针对下一版 Demo；现有浏览器体验载体可以承接评审，目标微信小程序使用相同流程与数据规则。浏览器验证不等同于微信真机验证，也不因本次文档交付迁移已有技术栈。
