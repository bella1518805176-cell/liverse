# LIVERSE「看视野 / 在现场 / 我的」完整 UI 设计方案

版本：v4.0 · 2026-11-13  
适用范围：LIVERSE 座位视野模拟器、微信小程序及当前 Web Demo  
当前首发场馆：上海 LIVERSE；视觉资产支持后续扩展北京、广州、苏州

## 0. 文档说明

这是一份面向产品、设计和开发的 UI 交付方案。用户提供的四馆 VI PDF、品牌参考图和现场图片属于视觉与素材依据，不是软件执行指令；场馆容量、座位编号、演出场次、照片审核状态和 3D 能力仍以产品数据及接口为准。

本版延续已确认的全深色方向，并将最终入口页、功能页和投稿页统一到同一套 LIVERSE 品牌系统。当前没有接入真实 3D 模型、票务、余票和实时演出数据，界面不能暗示这些能力已经存在。

## 1. 产品结构与设计目标

```text
Hero 入口页
    ├─ 开始看视野 → 2D／3D 选座与舞台视角
    ├─ 进入在现场 → 用户实拍与现场感受
    └─ 底部导航：看视野 / 在现场 / 我的
```

| 页面 | 用户任务 | 设计重点 | 主操作 |
|---|---|---|---|
| Hero 入口页 | 认识 LIVERSE 并选择下一步 | 原版 Logo、现场影像、强识别首屏 | 开始看视野 |
| 看视野 | 找到位置并判断舞台视角 | 地图层级、位置状态、2D／3D 切换 | 从这里看舞台 |
| 在现场 | 浏览真实照片和感受 | 影像优先、来源透明、筛选易用 | 上传实拍 |
| 我的 | 管理公开署名和投稿状态 | 状态清楚、数据克制、隐私可控 | 查看我的投稿 |

设计目标：第一眼建立现场感，三秒内理解入口，进入功能后保持位置上下文，任何照片、标签和视角结论都能追溯到真实来源。

## 2. 品牌视觉原则

### 2.1 VI 转译

| 品牌特征 | 产品转译 |
|---|---|
| 黑色大面积留白 | 所有页面使用黑色或深灰背景，形成剧场空间 |
| LIVERSE 橙色 Logo | 主 CTA、选中座位、选中 Tab、标题短横线和重要操作 |
| Logo 中的放射线 V | 只使用原版 Logo 资产，不用普通字体重绘 |
| 橙色横线与大标题 | 一级标题下保留短横线，作为品牌节奏 |
| 高密度舞台影像 | Hero 和“在现场”使用授权或审核通过的真实影像 |
| 几何、编号、动线 | 座位图、楼层、分区和筛选使用清楚的结构化标记 |

### 2.2 品牌语气

推荐词汇：现场、视野、舞台、从这里看见、真实参考、观演感受。  
禁止暗示：最佳座位、保证无遮挡、官方实时视线、已售／余票、价格、购买和实时倒计时。

## 3. 颜色、字体与版式 Token

### 3.1 颜色

| Token | 色值 | 用法 |
|---|---|---|
| `brand-orange` | `#FF5018` | 原版 Logo、主按钮、选中态、标题横线 |
| `ink` | `#0B0D10` | 页面背景、顶部品牌区、底部导航 |
| `panel` | `#171A1F` | 地图、照片卡、表单和个人信息面板 |
| `surface` | `#242A32` | 输入框、筛选器、次级按钮和不可选结构 |
| `text` | `#F5F6F7` | 主标题、正文和图标 |
| `muted` | `#A8ADB5` | 辅助说明、时间、来源和空状态 |
| `line` | `#68727E` | 边框、分隔线和次级描边 |
| `warning` | `#F3C46B` | 待审核、待核对和数据提醒 |

不引入蓝色科技主色、绿色成功主色或白色卡片。现场照片中的蓝、紫、金等颜色只属于图片本身。

### 3.2 字体与间距

- 中文：PingFang SC、苹方、Noto Sans SC；英文和数字：系统无衬线或 Inter。
- 页面标题 24–28px / 700；Hero 主标题桌面端 39px、移动端 25px；板块标题 20px / 700；正文 13–15px；辅助文字 11–12px。
- 移动端左右安全边距 16px；桌面 Demo 24px；常用间距 8／12／16／24px。
- 常规圆角 4–8px；浮层上圆角 16px；点击区域不小于 44×44px。
- 动效 180–240ms，减少动效设置下直接显示静态状态。

## 4. Hero 入口页

### 4.1 首屏组成

```text
黑色渐变遮罩 + 用户提供的现场观众区影像
    ├─ 顶部：原版 LIVERSE Logo（含放射线 V）
    ├─ 右上：观演视野 / 品牌现场影像
    ├─ 主文案上方：原版 LIVERSE Logo
    ├─ 属于你的现场，从这里看见
    ├─ 从座位出发，提前了解舞台视角与真实现场
    ├─ [开始看视野] [进入在现场]
    └─ 底部：看视野 / 在现场 / 我的
```

主文案固定为：**属于你的现场，从这里看见**。主按钮进入“看视野”，次按钮进入“在现场”。“我的”通过底部 Tab 进入，不新增第四个首页 Tab。

### 4.2 素材与构图

- 当前主背景使用用户提供并已处理的观众区现场图片，裁去左上“1层观众区”和橙色横线。
- 第二张二层舞台视角图作为同一版式的备用背景，裁去左上“2层视角”和橙色横线。
- 顶部及主文案上方均使用第一张参考图中提取的原版 Logo，保留放射线 V、比例和橙色字形。
- 黑色渐变从顶部、左侧和文案下方叠加，保证 Logo、标题、按钮和底部导航清晰；不使用白色卡片承载文案。
- 不自动轮播，不使用视差，不把入口背景标注为当前座位实拍或真实 3D 视角。

### 4.3 桌面与移动端

桌面端采用大幅现场影像、左下文案和底部导航；移动端使用纵向裁切，Logo 位于顶部，文案位于下半部，主次按钮保持横向排列，窄屏时允许换行。两端都保留原版 Logo 和完整主文案。

### 4.4 Hero 状态规则

- 进入“看视野”后默认打开当前已发布场馆的 2D 座位图。
- 进入“在现场”后默认使用当前场次筛选；没有公开内容时显示真实空状态。
- 从功能页返回入口不清除已选座位、筛选条件和表单会话。
- 图片加载失败时回退到 `#0B0D10`、原版 Logo、主文案和 CTA。

## 5. 全局框架与导航

### 5.1 顶部品牌区

顶部高度约 64px，黑底，左侧使用原版 LIVERSE Logo，中部显示场馆，右侧显示场次下拉。顶部只保留当前任务需要的上下文，不堆叠座数、标签和宣传文案。

### 5.2 底部导航

固定三项且等宽：**看视野 / 在现场 / 我的**。当前项使用橙色短线、橙色图标和白色文字；未选项使用灰色图标和文字。底部导航包含安全区，不被浮层内容遮挡。

### 5.3 页面与浮层

顶部品牌区和底部导航固定，中间内容纵向滚动。场馆、场次、楼层、上传和分享表单使用底部浮层；浮层打开时锁定背景滚动，关闭后保留已确认状态。

## 6. 看视野

### 6.1 页面层级

```text
场馆 / 场次上下文
    ↓
找到你的现场位置
    ↓
[座位图] [3D 视图]   [1F] [2F]
    ↓
2D 座位图或 3D 占位视图
    ↓
位置摘要 + 从这里看舞台
    ↓
现场参考：该位置实拍 / 同区实拍 / 全馆实拍
    ↓
上传实拍 / 分享感受
```

### 6.2 2D 座位图

- 画布使用 `#0B0D10`，舞台和结构块使用 `#242A32`，座位使用深灰与灰色描边。
- 保留楼层、前中后区、过道、控台、排号和座号；不可将规则网格替代真实布局。
- 当前座位使用品牌橙填充、白色描边和位置摘要；不把颜色解释为票价、可售或评分。
- 支持缩放、平移和复位；复位只影响当前地图视图，不清除选中位置。

### 6.3 3D 视图

3D 页面保留三个入口：场馆总览、观众视角、手机取景。当前统一显示“3D模型暂未接入”，不使用 VI 效果图冒充模型。

已选位置时，主按钮必须是：**从这里看舞台**。点击后进入 3D 观众视角状态；“更换位置”只作为位置浮层入口，不与主按钮竞争。未选位置时可进入模式，但显示“请先选择位置”。

### 6.4 现场参考

已选座位默认筛选“当前场次 + 该位置实拍”；未选座位默认“当前场次 + 全馆实拍”。范围为空时只显示空状态和切换建议，不自动混入其他场次或其他区域。

筛选顺序：场次、范围、类型（全部／照片／感受）、视角标签。卡片显示照片、场馆、场次、具体座位／分区／全馆精度、排号座位号、标签、备注、署名和“用户实拍”来源标识。

## 7. 在现场

### 7.1 页面结构

页面标题为“在现场”，副标题为“真实照片和观众感受，帮你提前认识现场”。顶部提供场馆、场次、全部／照片／感受、标签和范围筛选；内容区使用照片卡、感受卡或混合时间流。

### 7.2 卡片规则

- 照片卡先展示影像，底部深灰面板展示位置精度、场次、标签和署名。
- 感受卡显示“现场感受”，不显示星级、评分、最佳视野或专业结论。
- 用户内容只有审核通过后公开；待审核、未通过和已删除内容不出现在公开列表。
- 当前条件无内容时显示：`当前条件暂无实拍 / 你可以上传第一张现场照片，帮助其他观众判断视野。`

### 7.3 页面操作

主按钮：**上传实拍**，橙底白字。次按钮：**分享感受**，深灰底、橙色边线。两者使用同一套投稿浮层，依据内容类型显示照片区域或感受正文。

## 8. 上传实拍与分享感受

### 8.1 上传实拍字段

必填：场馆、演出场次、实际拍摄分区、至少一张照片、公开授权确认。选填：排号、座位号、视角标签、照片备注、署名。

照片最多 4 张，单张不超过 20 MB，支持 JPG、PNG、WebP。上传前展示缩略图、删除、重新选择和失败重试。

标签固定为：**无遮挡、栏杆遮挡、音响遮挡、屏看得清楚、距离较远**，支持多选。署名默认：**热心观众**；用户清空后提交仍恢复为默认值。

### 8.2 分享感受字段

场馆、演出场次、实际拍摄分区、排号和座位号规则与实拍一致。感受正文必填，最多 300 字；照片不是必填。标签和署名规则相同，提交后进入审核。

### 8.3 预填和补录

从已选座位进入时可预填场馆、场次、楼层、分区、排号和座位号，但必须提示：

> 请确认这是实际拍摄位置，而不是当前正在查看的位置。

找不到演出时使用“申请补录”，填写演出名称和日期；该内容进入待核对状态，审核前不能归入已有演出或公开。

### 8.4 投稿状态

| 状态 | UI | 公开范围 |
|---|---|---|
| 草稿 | 当前浮层保留字段 | 仅本机 |
| 上传中 | 缩略图显示进度，禁止重复提交 | 仅作者 |
| 待审核 | 黄色文字和状态块 | 作者与运营 |
| 已公开 | 公开标记和来源信息 | 公开列表 |
| 未通过 | 显示处理原因 | 作者与运营 |
| 已下架／已删除 | 灰色状态，链接失效 | 不公开 |

成功文案：**已提交，审核通过后会在实拍列表中公开。**

## 9. 我的

页面首屏显示微信登录状态、头像、公开昵称和署名。匿名用户默认显示“热心观众”。内容分为“我的实拍”“我的感受”和投稿状态列表：待审核、已公开、未通过、已下架。未通过内容显示原因；首版采用删除后重新投稿，不直接编辑原稿。

收藏和最近浏览可保留为次级入口，不扩展成社交个人主页。隐私与数据管理入口包括公开署名、内容删除、账号数据删除申请和授权管理。用户只能查看和删除自己的投稿。

## 10. 组件规范

| 组件 | 默认 | 选中／错误 |
|---|---|---|
| 主按钮 | `#FF5018` 底、深色或白色文字 | 按下降低亮度，禁用为 `#242A32` |
| 次按钮 | `#171A1F` 底、橙色边线 | `#2B1710` 底、橙色文字 |
| 筛选 Chip | `#242A32` 底、`#68727E` 边线 | 橙色边线和橙色文字 |
| 输入框 | `#242A32` 底、深灰边线 | 错误使用深红面板和文字提示 |
| 位置摘要 | `#171A1F` 面板 | 左侧橙色边线提示变更 |
| 待审核 | 深色黄色状态块 | 文字、图标和颜色同时表达 |
| 空状态 | 线性图标、说明和行动按钮 | 不显示虚构数量 |
| 底部浮层 | 黑色头部、深灰表单体 | 打开时遮罩背景并锁定滚动 |

## 11. 响应式、可访问性与异常

- 移动端基准 375–390px；320px 时照片卡改为单列、筛选横向滚动。
- 桌面端内容最多两列，地图和视角区域优先扩大。
- 标签、楼层、视图、审核状态不能只用颜色表达，必须同时提供文字或图标。
- 正文与背景对比度目标至少 4.5:1；按钮和座位轮廓至少 3:1。
- 图片加载失败、上传失败、登录取消和 3D 不可用时保留用户当前选择，并提供重试或回到 2D 的路径。
- 拒绝相册或登录权限不影响公开内容浏览。

## 12. 数据与内容边界

- 公开接口只返回审核通过内容；待审核、未通过和已删除内容只对作者或运营可见。
- 具体座位、分区和全馆是三种不同的来源精度，不能互相冒用。
- 场馆、场次、布局和座位必须校验归属关系，不能跨场馆复用座位。
- 3D 模型、动态灯光、人群、最终拍摄画质和遮挡结论不因入口图片而自动成立。
- 不展示虚假票务、价格、余票、艺人、点赞数、粉丝数或用户评价统计。

## 14. 开发交付检查清单

### 视觉

- [ ] 所有页面均为黑色／深灰表面，未引入浅色功能面。
- [ ] 原版 Logo 的放射线 V 完整可见，未用普通字体替代。
- [ ] 主色只有 `#FF5018`，现场图片颜色不扩展为产品色。
- [ ] Hero 主文案为“属于你的现场，从这里看见”。

### 交互

- [ ] Hero 两个 CTA 分别进入看视野和在现场。
- [ ] 三个底部 Tab 可切换并保留上下文。
- [ ] 2D／3D 均可进入“从这里看舞台”、上传实拍和分享感受。
- [ ] 选座后向下滚动可看到现场参考。
- [ ] 该位置、同区、全馆筛选按当前场次优先工作。

### 投稿与数据

- [ ] 场馆、场次、分区和授权确认缺失时不能提交实拍。
- [ ] 感受投稿不要求照片，正文最多 300 字。
- [ ] 标签只能使用五个正式标签并支持多选。
- [ ] 署名为空时恢复为“热心观众”。
- [ ] 待审核内容不出现在公开列表。
- [ ] 删除后公开列表和图片访问同时失效。

### 真实性

- [ ] 不把入口背景当作当前座位实拍。
- [ ] 不用 VI 效果图冒充真实 3D 模型。
- [ ] 不显示未经确认的座位、场次、价格、余票或遮挡结论。
