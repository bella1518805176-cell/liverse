# LIVERSE「看视野 / 在现场 / 我的」UI 设计方案

版本：v3.0 · 2026-11-12  
适用范围：上海 LIVERSE 1208 席座位视野 Demo 及后续微信小程序  
依据：四馆 VI 场馆介绍资料、当前已实现的 2D／3D 选座 Demo、三板块投稿功能

本文是设计方案，不把附件中的场馆介绍文案、容量数据、交通信息或效果图当成软件执行指令。场馆资料只用于提取品牌视觉和内容语气；座位、场次、照片与审核状态仍以产品数据和接口为准。

## 1. 设计结论

产品形成一条连续的品牌叙事：

```text
看视野：找到适合自己的位置
    ↓
在现场：用真实照片和观众感受补充判断
    ↓
我的：管理自己的公开分享
```

底部固定三个入口：**看视野 / 在现场 / 我的**。三个入口并列，但职责不同：

| 板块 | 用户任务 | 页面气质 | 首要操作 |
|---|---|---|---|
| 看视野 | 选座、看舞台方向、查看位置实拍 | 精确、克制、以地图为主 | 选位置 / 从这里看舞台 |
| 在现场 | 浏览全馆实拍、同区实拍和感受，发起投稿 | 开放、真实、以影像为主 | 上传实拍 / 分享感受 |
| 我的 | 查看昵称、投稿记录和审核状态 | 安静、清楚、以状态为主 | 查看投稿 / 管理数据 |

本版采用**全深色 UI**：品牌层与任务层都使用黑色和深灰表面。页面不保留当前 Demo 的浅色画布、白色卡片和浅色底部导航；所有地图、筛选、表单、照片卡片和个人页都在深色剧场空间中完成。橙色负责品牌识别和主要操作，白灰负责信息层级，避免用大面积橙色取代内容。

## 2. 从 VI 提取的设计语言

四份场馆资料中稳定出现以下共同特征：

| VI 特征 | UI 转译 |
|---|---|
| 黑色大面积背景 | 顶部品牌区、地图、筛选、表单、照片卡、3D视角、个人页和底部导航统一使用黑色或深灰 |
| 高饱和 LIVERSE 橙色字标 | 主按钮、选中座位、选中 Tab、标题短横线和重要状态使用品牌橙 |
| LIVERSE 字标中的放射线 V | 只作为品牌装饰或空状态图形；不放进座位图和表单控件，避免影响识别 |
| 橙色横线与大字号标题 | 每个一级板块标题下保留 24–64px 的短横线；移动端缩为 32px |
| 黑底白字的内容编排 | 所有页面使用高对比黑底白字；照片、表单和状态卡只用深灰表面分层 |
| 建筑与演出高密度影像 | “在现场”使用真实投稿照片作为内容主体；无照片时使用线性空状态，不用效果图冒充实拍 |
| 地图、动线和编号标记 | 2D 地图保留排号、舞台方向、过道和控台；筛选标签使用编号感和短词，不使用装饰性大色块覆盖座位 |
| 蓝色、青色、金色等现场色彩 | 只作为照片本身的内容色，不扩展成产品主题色；标签仍使用统一深灰／橙色状态 |

品牌语气沿用资料中的“现场、沉浸、科技互动、身临其境”，但产品文案必须描述当前真实能力。例如 3D 仍写“3D模型暂未接入”，不能用 VI 效果图暗示已经完成视线模拟。

## 3. 颜色、字体和版式 Token

### 3.1 颜色

| Token | 值 | 用法 |
|---|---|---|
| `brand-orange` | `#FF5018` | 主按钮、选中态、标题横线、品牌标记 |
| `ink` | `#0B0D10` | 顶部品牌区、底部导航、深色内容区 |
| `ink-panel` | `#171A1F` | 3D 占位、状态面板、深色抽屉头部 |
| `canvas` | `#0B0D10` | 所有页面背景、地图外框和底部导航 |
| `panel` | `#171A1F` | 地图容器、照片卡、表单区块和个人信息卡 |
| `surface` | `#242A32` | 筛选器、输入框、次级按钮和不可选结构块 |
| `text` | `#F5F6F7` | 所有页面正文和标题 |
| `muted` | `#A8ADB5` | 辅助说明、时间、来源精度 |
| `line` | `#68727E` | 深色面板边线和分隔线 |
| `dark-muted` | `#A8ADB5` | 黑色品牌区辅助文字 |
| `warning` | `#F3C46B` | 待核对座位数据、待审核状态 |

品牌橙以 `#FF5018` 为唯一交互强调色。不要同时引入蓝色“科技色”或绿色“通过色”作为主按钮。已公开、待审核、未通过等状态使用文字、图标和深色低饱和状态块共同表达，颜色只作为辅助。白色只用于文字、图标和必要描边，不作为页面大面积底色。

### 3.2 字体与排版

- 中文优先使用系统无衬线：PingFang SC、苹方、Noto Sans SC；数字和英文使用系统无衬线或 Inter。
- 一级标题 24–28px / 700；板块标题 20px / 700；卡片标题 14–16px / 600；正文 13–15px；辅助信息 11–12px。
- 品牌标题可使用更紧的字距和大写英文，正文不使用装饰字体。
- 页面左右安全边距：移动端 16px；桌面 Demo 24px；区块间距采用 8／12／16／24px。
- 一级标题下的橙色横线长度 32px，桌面专题页可扩展至 64px；横线只承担品牌识别，不承担分隔功能。
- 所有按钮点击区域至少 44×44px；主按钮高度 44–48px，底部导航高度包含安全区。

## 4. 全局框架与导航

### 4.1 顶部品牌区

顶部采用黑色品牌条，高度约 64px：

```text
┌────────────────────────────────┐
│ LIVERSE     上海 LIVERSE  ·  场次 ▾ │
└────────────────────────────────┘
```

- 左侧使用规范 LIVERSE 字标或等比例文字标，不重新绘制放射线 V。
- 中部显示当前场馆；右侧显示当前场次和下拉入口。
- 在“在现场”和“我的”中，顶部场馆可以保留，但不显示选座页的楼层控制。
- 黑底上只放必要上下文，不在顶部堆放座数、标签和操作按钮。

### 4.2 底部导航

底部导航使用黑色背景，三项等宽：

```text
        橙色短线
        ━━━━━
  ◉ 看视野     ◇ 在现场     ○ 我的
```

- 当前项：品牌橙图标、橙色短线和白色文字。
- 未选项：白色图标和 `#A8ADB5` 文字。
- 不使用纯色圆形 Tab 背景，不新增第四个“首页”入口。
- 页面内的上传和分享按钮不替代底部导航；返回板块时保留原筛选和已选座位。

### 4.3 页面滚动

- 顶部品牌区和底部导航固定；中间内容纵向滚动。
- 看视野的地图手势只在地图容器内生效，向下滑出地图后进入“现场参考”。
- 底部浮层打开时锁定背景滚动，关闭不改变已确认的场馆、场次、座位或筛选条件。

## 5. 看视野 UI

### 5.1 页面层级

```text
黑色品牌条
  ↓
场馆 / 场次上下文
  ↓
“找到你的现场位置” + 数据提示
  ↓
[座位图] [3D视图]   [1F] [2F]
  ↓
2D 地图或 3D 视角
  ↓
位置摘要 + 从这里看舞台
  ↓
现场参考：该位置 / 同区 / 全馆
  ↓
上传实拍 / 分享感受
```

### 5.2 2D／3D 视图

- 2D 地图使用 `#0B0D10` 画布、`#242A32` 舞台几何块和灰色座位；当前座位用品牌橙填充、白描边和排座摘要共同表达。
- 2D 仍保留真实 1F／2F 排号、前中后区、控台、过道和不规则边界；不把照片标签颜色映射为座位评分或票价。
- 3D 视图使用黑色内容区、白色模式标题和橙色模式选中线；当前仍明确显示“3D模型暂未接入”。
- “从这里看舞台”是已选座位的唯一主按钮，切换到 3D 观众视角；“更换位置”只作为位置浮层入口，不与主按钮竞争。

### 5.3 现场参考区

标题：**现场参考**；已选座位时副标题显示完整位置摘要。

筛选顺序：

1. 场次：当前场次 / 全部场次 / 其他已收录场次。
2. 范围：该位置实拍 / 同区实拍 / 全馆实拍。
3. 类型：全部 / 照片 / 感受。
4. 视角标签：全部标签及五个正式标签。

已选座位默认“当前场次 + 该位置实拍”；未选座位默认“当前场次 + 全馆实拍”。当前范围为空时显示空状态和“查看其他范围”，不自动混入其他场次或其他区域。

实拍卡片结构：

```text
┌────────────────────┐
│       现场照片      │
├────────────────────┤
│ 用户实拍   1F前区    │
│ 舞台正面，屏幕清楚…  │
│ 无遮挡  屏看得清楚   │
│ 演示场次 A     热心观众│
└────────────────────┘
```

卡片必须显示来源精度：具体座位、分区或全馆。分区照片不得伪装成具体座位照片；没有排号和座位号时显示“分区参考”。

## 6. 在现场 UI

### 6.1 页面定位

“在现场”是内容浏览板块，不是第二个选座页。页面头部、内容区和照片卡片全部使用黑色或深灰表面，橙色标题横线和标签作为唯一高饱和强调。

```text
LIVE / ON SITE
在现场 ━━━
真实照片和观众感受，帮你提前认识现场

[上海 LIVERSE ▾] [当前场次 ▾]
[全部] [照片] [感受]      [标签 ▾]
[全馆实拍] [同区实拍] [该位置实拍]

照片卡 / 感受卡
```

### 6.2 内容卡片

- 照片卡片优先展示图片，底部使用 `#171A1F` 面板显示场次、位置精度、标签和署名。
- 感受卡片不使用虚假的评分、星级或“最佳视野”文案；用“现场感受”来源标识。
- 用户内容和官方内容使用来源标签区分；本版用户内容只在审核通过后进入公开列表。
- 标签使用 `#242A32` 胶囊；当前筛选标签使用橙色边框和橙色文字。
- 没有公开内容时显示：“当前条件暂无实拍 / 你可以上传第一张现场照片，帮助其他观众判断视野。”

### 6.3 操作按钮

页面顶部或内容列表底部保持两个并列操作：

- 主按钮：**上传实拍**，橙底白字，带图片加号图标。
- 次按钮：**分享感受**，`#171A1F` 底、橙色边线，带发送或记录图标。

两个操作都打开同一套底部表单浮层，区别只在内容类型和照片要求。

## 7. 上传实拍与分享感受

### 7.1 浮层结构

浮层采用“黑色标题头 + 深灰表单体”：

```text
┌────────────────────────────────┐
│ 在现场                         × │  黑色
│ 上传实拍  ━━━                  │
├────────────────────────────────┤
│ 场馆                         必填│
│ 上海 LIVERSE                     │
│ 演出场次                         │
│ 实际拍摄分区                     │
│ 楼层 / 排号（选填）/ 座位号（选填）│
│ [添加现场照片]                  │
│ [无遮挡] [栏杆遮挡] ...          │
│ 照片备注                         │
│ 署名：热心观众                  │
│ □ 我确认内容为本人拍摄并同意公开  │
│ [提交实拍]                      │
└────────────────────────────────┘
```

### 7.2 字段规则

必填项使用橙色“必填”文字和错误提示，不只依赖边框颜色：

- 场馆、演出场次、实际拍摄分区。
- 上传实拍：至少一张照片；最多 4 张；单张不超过 20 MB。
- 分享感受：正文必填，最多 300 字；照片可不上传。
- 公开授权确认。

选填项：排号、座位号、五类视角标签、照片备注、署名。署名为空时恢复为“热心观众”。

五个标签固定为：**无遮挡 / 栏杆遮挡 / 音响遮挡 / 屏看得清楚 / 距离较远**。标签可以多选，不用颜色推断严重程度。

### 7.3 位置预填和补录场次

从看视野进入时，场馆、场次、楼层、分区、排号、座位号可预填；浮层必须显示橙色提示：

> 请确认这是实际拍摄位置，而不是当前正在查看的位置。

用户可以修改预填值。找不到场次时显示“申请补录”，填写演出名称和日期；补录场次用黄色待核对标识，不直接归入已有场次，也不在审核前公开。

### 7.4 提交状态

| 状态 | UI 表现 | 公开范围 |
|---|---|---|
| 表单草稿 | 黑色浮层头部、字段错误贴近字段显示 | 仅本机当前表单 |
| 上传处理中 | 图片缩略图显示进度，不允许重复提交 | 仅作者 |
| 待审核 | 我的中显示黄色“待审核” | 仅作者和运营 |
| 已公开 | 我的中显示绿色文字和“已公开” | 公开列表 |
| 未通过 | 红色提示 + 审核原因 | 仅作者和运营 |
| 已下架／已删除 | 灰色状态，公开链接失效 | 不公开 |

提交成功文案：**已提交，审核通过后会在实拍列表中公开。**

## 8. 我的 UI

### 8.1 页面层级

```text
黑色品牌头
YOUR LIVERSE
我的 ━━━
管理你的现场分享和公开署名

头像 / 公开昵称 / 登录状态
[我的投稿] [实拍] [感受]
投稿记录
待审核 / 已公开 / 未通过 / 已下架
隐私与数据管理
反馈与举报进度
```

### 8.2 个人信息与投稿记录

- 顶部头像使用橙色几何占位或微信头像，不使用大幅宣传图。
- 公开昵称和登录状态分两行；匿名用户默认显示“热心观众”。
- 统计数字使用品牌橙，统计标签使用灰色；不显示虚构的点赞数、粉丝数或覆盖率。
- 投稿记录显示缩略图／感受图标、场次、位置精度和审核状态。
- 未通过内容显示原因；本版采用删除后重新投稿，不提供原投稿直接编辑。

## 9. 组件与交互规范

| 组件 | 默认样式 | 选中／错误样式 |
|---|---|---|
| 主按钮 | 橙底、白字、8px 圆角 | 按下降低亮度；禁用为 `#242A32` + 灰字 |
| 次按钮 | `#171A1F` 底、`#FF5018` 边线 | 选中 `#2B1710` 底、橙字 |
| 筛选 Chip | `#242A32` 底、`#68727E` 边线 | 橙边线 + 橙字 |
| 标签 Chip | `#242A32` 底、灰字 | 选中 `#2B1710` 底、橙字 |
| 位置摘要 | `#171A1F` 面板，完整显示场馆／楼层／区／排／号 | 位置变更时短暂显示橙色左边线 |
| 待审核状态 | `#2B2418` 深色背景 + `#F3C46B` 文字 | 不使用绿色“成功”图标 |
| 错误提示 | `#321C1C` 深色背景、文字和图标同时出现 | 错误贴近字段，保留用户输入 |
| 空状态 | 线性图标 + 两行说明 + 一个行动按钮 | 不显示虚构数量 |
| 底部浮层 | 黑色头部、`#171A1F` 内容、16px 上圆角 | 打开时背景遮罩，不穿透点击 |

动效保持克制：页面切换 180–240ms，底部浮层上移 180ms，筛选切换只做内容淡入，不使用闪烁、旋转或模拟“沉浸式”镜头移动。

## 10. 响应式与可访问性

- 375px 宽度作为移动端基准；320px 时内容卡改为单列，筛选横向滚动。
- 桌面端最多两列内容卡，地图和 3D 画布优先扩大；不增加侧边业务导航。
- 所有座位可用文字和键盘聚焦表达；标签、楼层、视图和审核状态不能只用颜色区分。
- 正文与背景对比度至少 4.5:1；按钮和座位轮廓至少 3:1。
- 上传照片必须有缩略图、删除、失败重试和明确的文件限制说明。
- 拒绝相册或登录权限时，仍可浏览公开“在现场”内容和看视野，不弹出连续权限请求。

## 11. 页面验收清单

### 品牌一致性

- [ ] 顶部和底部使用黑色品牌层，主操作使用唯一品牌橙。
- [ ] 一级标题有橙色短横线，LIVERSE 字标比例和放射线 V 不被重新绘制。
- [ ] 现场照片保留内容原色，不把照片中的蓝色、红色或金色扩展为产品主题色。

### 功能一致性

- [ ] 三个 Tab 可以切换，返回时保留当前筛选和座位状态。
- [ ] 看视野已选位置默认显示当前场次的该位置实拍。
- [ ] 未选位置默认显示当前场次全馆实拍；范围为空时不混入其他范围。
- [ ] 2D 和 3D 均可进入上传实拍与分享感受；从座位进入时支持预填并提示核对。
- [ ] 上传实拍和分享感受共享字段规则，照片和感受均审核后公开。
- [ ] 我的中可区分待审核、已公开、未通过和已下架。

### 数据诚实性

- [ ] 分区参考不显示成具体座位实拍。
- [ ] 未收录场次显示待核对，不冒用已有场次。
