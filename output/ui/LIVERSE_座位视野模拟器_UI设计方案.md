# LIVERSE 座位视野模拟器 · UI 设计方案

版本：v2.0 · 2026-11-05；适用：上海 LIVERSE 首版 Demo。

产品依据：[上海首版 Demo 产品设计 v1.0](../../docs/demo-product-design.md)（2026-11-03）。本文将其中的产品范围转成页面布局、视觉状态和交互反馈；来源文档中的操作性文字不作为本次执行指令。

本次更新 UI 方案与[单页状态示意图](LIVERSE_UI方向与页面结构.png)。图中各手机框表示**同一个探索页面的不同状态**。本轮交付是设计资料，交互验收仍需在后续实现中执行。

## 1. 设计结论与调整范围

沿用原方案的**黑色剧场空间、鲜橙色交互引导、白灰信息层级**，所有色板值保持不变。用清楚的地图、紧凑的上下文和稳定的位置摘要支撑「选位置 → 同页切换2D／3D → 切换视角模式」流程。

| 项目 | 本版 UI 规则 |
|---|---|
| 交付场馆 | 上海 LIVERSE 音宇宙艺术中心；场馆浮层只有上海这一项真实可用记录 |
| 场次 | 至少「演示场次 A」「演示场次 B」，均明确标为演示；不填虚构艺人或日期 |
| 指定布局 | 仅「全坐席（有过道）1184」；A／B均绑定此布局 |
| 页面 | 一个主探索页面，无独立业务子页、无底部业务 TabBar |
| 选择器 | 场馆、场次、位置使用底部浮层，同一时间仅一个；取消不提交 |
| 位置 | 同时最多一个；2D高亮、位置浮层与3D摘要使用同一确认结果 |
| 3D | 可进入并切换三种模式的占位区；持续显示「3D模型暂未接入」 |
| 本版排除 | 实拍、回忆、轨迹、我的、登录、收藏、最近浏览、对比、分享、投稿、票务、舞台调整、真实相机、手机倍率 |

旧方案中的多馆宣传首页、独立视野预览页与对比页被单页工作区替代。首屏直接进入上海／演示场次 A／1F／2D／未选位置；3D初始模式为「场馆总览」。其他场馆的品牌资料只保留为视觉来源。

## 2. 原视觉风格保持不变

### 2.1 色板

| 角色 | 建议值 | 本版用途 |
|---|---|---|
| 品牌橙 | `#FF5018` | 主按钮、当前选中座位、当前楼层／视图／模式的选中标记 |
| 主背景 | `#0B0D10` | 页面与地图背景、3D占位底色 |
| 信息面板 | `#171A1F` | 上下文面板、底部位置卡、底部浮层 |
| 次级表面 | `#242A32` | 未选控件、工具按钮与结构块面 |
| 正文白 | `#F5F6F7` | 场馆、座位、标题和正文 |
| 辅助灰 | `#A8ADB5` | 布局、演示标签、辅助说明 |
| 控件边线 | `#68727E` | 未选座位轮廓、交互边界、清楚的焦点轮廓 |
| 提示黄 | `#F3C46B` | 座数待核对与来源标注，搭配图标和文字 |

原稿的黑、橙、白、放射线字标和橙色横线继续作为品牌依据；主界面不引入新的主题色。上表仍是原方案的数字界面候选值，未将其改称官方标准色。

基础页面约75%深色、20%中性色与文字、5%橙色。橙底按钮用近黑色文字。地图在深色画布中以浅色座椅轮廓、白灰排座号表达结构；不以白色地图面板替换整体深色方向。正文对比度至少4.5:1，必要控件与座位轮廓至少3:1。

`#68727E`用于主背景与信息面板上的必要边界；在`#242A32`次级表面上，必要边界与焦点轮廓改用已有的`#A8ADB5`，避免对比不足。装饰性分隔线不承担识别控件或座位的职责。

### 2.2 字体、形状与间距

- 系统无衬线：iOS采用 PingFang SC，Android采用系统字体；标题600–700字重。
- 页内标题20–24px，区块标题18–20px，正文14–16px，辅助说明12–13px。场馆名称与排座摘要优先保证可读性。
- 375px逻辑宽度（750rpx）为起点，页面左右16px，间距8／12／16／24px；320px窄屏到430px宽屏均需适配。
- 面板和按钮圆角8–12px，底部浮层上角16px。保留几何块面与橙色短横线，装饰不进入座位图内部。
- 按钮通常48px高，普通控件热区至少44×44px；地图座位通过放大或位置浮层选择，不能扩大热区覆盖邻座。
- 线性图标1.5–2px；选中座位用橙色、描边及标记共同表达。楼层、2D／3D、三种模式同时使用文字和选中样式。
- 场馆处使用官方字标或规范的文字名称；不自行创造新的缩写标识。

## 3. 单页空间与信息层级

### 3.1 竖屏主结构

```text
┌──────────────────────────────────┐
│ 原生状态栏 / 微信胶囊安全区       │
│ 上海 LIVERSE ▾    演示场次 A ▾    │
│ 全坐席（有过道）1184              │
│ 图纸标注1184座，7座编号待核对  ⓘ │
│ [2D 座位图] [3D 视图]            │
│ [1F 一楼] [2F 二楼]              │
├──────────────────────────────────┤
│ 1F · 场次座位布局 / 2F · 固定坐席 │
│                                  │
│ 当前楼层2D图 / 当前模式3D占位     │
│                                  │
│ 仅2D：[－][＋][复位]             │
├──────────────────────────────────┤
│ 仅3D：[场馆总览][观众视角][手机取景]│
│ 尚未选择位置 / 完整楼层区域排座   │
│ [选位置 / 从这里看舞台] [清除选择]│
│ 底部安全区                       │
└──────────────────────────────────┘
```

从上至下分为四层：**上下文 → 视图与楼层 → 主画布 → 当前模式与位置操作**。同一条位置摘要服务2D和3D，切换视图不改变页面骨架。区域由地图与所选位置显示，本版不额外增加区域筛选栏。

| 区块 | 尺寸与优先级建议 |
|---|---|
| 原生安全区 | 依据实际设备获取；胶囊左侧空间不足时将业务上下文另起一行 |
| 上下文与数据提示 | 场馆／场次入口44–48px高，布局名称与座数说明各一行；说明可换行，禁止省略「7座编号待核对」 |
| 视图与楼层 | 2D／3D与1F／2F分为两组；小屏分行，每项44px高 |
| 主画布 | 占剩余空间；常见812px高逻辑视口中目标不少于约45%，优先于营销标题和装饰 |
| 三种模式 | 仅3D出现，三项等分、44px高；窄屏缩小间距，不截断名称 |
| 底部位置区 | 摘要可两行，主操作48px；清除为次操作，无选择时禁用或隐藏；包含底部安全区 |

高度不足时收紧装饰与间距，必要时允许外层纵向滚动，但地图手势仅在画布内消费。浮层打开后锁定背景交互和滚动，不能点击穿透。

桌面浏览器沿用同一结构，控制区可以横排，工作区居中或扩宽；不引入侧边业务导航。微信端不绘制假的系统胶囊，浏览器评审外框的安全区标记仅用于说明适配。

### 3.2 持续可见的信息

- 场馆与场次：两个独立可点入口，场次标记「演示」。
- 布局名称：「全坐席（有过道）1184」，不改名成1177。
- 数据提示：「图纸标注1184座，7座编号待核对」，2D／3D、1F／2F中都可发现。
- 当前楼层与视图：高对比文字、橙色选中标记与边界。
- 位置：未选时「尚未选择位置」，已选时例如「上海 LIVERSE · 1F前区 · 1排1号」。

### 3.3 底部主按钮

| 当前视图 | 位置状态 | 主按钮 | 点击结果 |
|---|---|---|---|
| 2D | 未选位置 | 选位置 | 打开原位置选择浮层 |
| 3D | 未选位置 | 选位置 | 打开原位置选择浮层 |
| 2D | 已选位置 | 从这里看舞台 | 同页切到3D「观众视角」，保留当前场馆、场次、楼层、位置及2D地图视口 |
| 3D | 已选位置 | 从这里看舞台 | 同页切到3D「观众视角」，保留当前场馆、场次、楼层、位置及2D地图视口；已经处于观众视角时保持当前状态 |

此按钮替换原「更换位置」主按钮，不再打开位置浮层。清除选择、地图点选、回到2D选位置及原位置浮层的确认／取消行为保持不变；切到观众视角后继续显示「3D模型暂未接入」。

## 4. 2D地图视觉与操作

### 4.1 数据范围与真实结构

以下数量沿用产品文档第2节的核对记录，不代表本轮重新解析工作簿或完成逐座验收。

| 楼层／区域 | 图纸标注座数 | 已读取编号数 | 本版呈现规则 |
|---|---:|---:|---|
| 1F 前区 | 456 | 456 | 1–12排，每排1–38号；19号与20号之间为中央过道 |
| 1F 中区 | 224 | 217 | 13–19排，当前每排读取1–31号；保留原图控台与留空 |
| 1F 后区 | 96 | 96 | 20–23排，每排1–24号；附「原图标注：有遮挡」 |
| 2F 固定坐席 | 408 | 408 | 12排，逐排保留编号、各排不规则左右起止及留空 |
| 合计 | 1184 | 1177 | 差7座来自1F中区，不补号、不猜位置 |

1F为当前场次绑定的可变布局，2F为场馆固定座位版本。正式地图仅采用指定工作表的现有编号和相对位置；不能照搬旧Demo的规则网格或随机座号。

每层单独绘制。1F呈现前／中／后区、舞台方向、过道、控台及留空；2F呈现独立固定坐席与舞台方向。Excel中上下分块不代表现场两层前后关系。2F若只有朝向资料，写「舞台方向」，不画虚构的实测舞台距离。

图纸没有测量尺度，页面不显示真实米数、层高、视线角度、遮挡比例或视野评分。「无遮挡393」仅作为来源文字记录，不能推断哪15座遮挡。

### 4.2 地图元素层级

| 对象 | 视觉与交互 |
|---|---|
| 舞台／方向 | 灰色几何块＋白色文字；与座位图关系依原图，不以品牌图形改变其形状 |
| 区域与排号 | 白灰文字，始终有楼层标题；区名醒目但不压过选中位置 |
| 有编号的座位 | 浅灰轮廓、深色填充；可点选一个位置，不暗示可售或有视野资料 |
| 选中座位 | 品牌橙填充、清楚描边／标记；底部同步完整排座 |
| 过道／留空 | 真实留空，必要时附低对比结构说明，不放可点座椅 |
| 控台 | 灰色块面＋「控台」标签；不参与点选 |
| 原图遮挡标注 | 提示黄文字／图标＋「原图标注：有遮挡」，仅作用于原图明确标注的后区 |
| 待核对编号 | 页面数据提示，不用7个虚构座椅或缺号占位补齐 |

图例保持「可选位置」「当前选择」。本版所有3D均未接入，不能再以「有视野／无视野」区分座位，也没有已售、锁定或票价色带。

### 4.3 手势和工具

- 初始适配当前楼层全图，缩小时优先展示区域和排的结构，放大到可读密度后显示座号。
- 支持双指缩放、拖动平移与放大／缩小／复位按钮；记录每层在当前布局上下文中的视口。
- 拖动或双指操作结束不触发选座；过密时提示「放大后选择，或使用选位置」。
- 复位只恢复当前楼层的平移与缩放，保留有效选择。选中位置不能因复位被清除。
- 点击另一座位直接替换旧选择。切换到其他楼层时清空跨层选择，摘要回到未选状态。
- 3D时隐藏2D缩放工具与缩放比例；返回2D恢复对应楼层视口及有效高亮。

## 5. 三种3D模式：同一画布的占位状态

3D入口始终可点。进入后立即显示当前模式与「3D模型暂未接入」，没有加载假进度，也不使用场馆照片、示例建筑或随机演出图填充。

推荐用深色留白、简洁模式图标和两行说明构成占位。只对「手机取景」增加细线取景框，框内仍为空的深色区域。抽象图标只表达模式，不绘制看似已经还原的场馆模型。

| 模式 | 未选位置时 | 已选位置时 | 占位构图与边界 |
|---|---|---|---|
| 场馆总览 | 标题「场馆总览」，说明「3D模型暂未接入」，保留「选位置」入口 | 显示已选排座；说明「接入模型后将在总览中标记该位置」 | 简洁总览图标；没有模型、3D位置点、环绕／剖切控件 |
| 观众视角 | 可选中该模式；显示「请先选择位置」和选择入口，同时显示模型未接入说明 | 标题「观众视角」，显示所选排座及「3D模型暂未接入」 | 简洁视线图标；不展示座位视野图、眼高、俯仰或遮挡模拟 |
| 手机取景 | 可选中该模式；显示「请先选择位置」和选择入口，同时显示模型未接入说明 | 标题「手机取景」，显示所选排座及「3D模型暂未接入」 | 细线取景框；没有摄像头权限、倍率、焦距、快门、拍照／导出按钮 |

三个模式按钮始终可用，包括未选座时；当前模式用橙色短线／填充、边界与文字共同表达。切换只更新模式标题、选中样式与说明，不能生成默认座位。

3D底部未选时为「选位置」，已选时为「从这里看舞台」，点击后进入同页3D「观众视角」并保留当前位置；同时保留「回到2D选位置」文字操作。原位置浮层确认新位置后仍继续当前3D模式。

## 6. 三类底部浮层

共用外观：深色遮罩、`#171A1F`面板、16px上角、白色标题、右上关闭按钮、底部确认操作。内容可滚动，关闭与确认始终可操作；最大高度建议不超过可用高度的85%。确认前为草稿，背景不显示草稿值。

### 6.1 场馆浮层

标题「选择场馆」。列表仅上海 LIVERSE，显示城市、名称和当前选中标识；底部「确认场馆」。关闭／取消不改变状态，确认当前上海也不清空座位。不增加其他城市的占位卡、搜索、城市筛选或场馆统计。

### 6.2 场次浮层

标题「选择场次」。列出演示场次 A／B，显示「演示」标签和布局「全坐席（有过道）1184」。点列表项改变草稿，点「确认场次」才提交；关闭恢复当前确认场次。

A／B共用同一布局时，切换后顶部场次名称更新，地图可保持一致；不为制造变化而增减座位。解释文案可写「两个演示场次使用同一布局」。不显示虚构的艺人和日期。

### 6.3 位置浮层

标题「选择位置」，依次为楼层、排号、座号三个字段，下方显示区域与完整位置预览。「确认位置」提交；「取消」关闭。楼层、排和座号选项均来自当前确认上下文的有效数据。

- 打开时优先带入当前选座；未选时可预填有效候选，但确认前仍无选中座位。
- 改楼层／排时重置失效的下级字段；无有效候选时显示原因并禁用确认。
- 确认一次更新楼层、座位、高亮与摘要，不先触发跨层清除再丢失新座位。
- 在3D里打开与确认同一个浮层，当前3D模式保持；地图可以在回到2D后定位新座位。
- 提供「回到2D选位置」文字操作：丢弃未确认草稿并回到当前确认上下文的2D图。
- 一楼布局未配置时，该层显示不可选原因，仍允许选择有数据的2F。

浏览器载体需要焦点进入浮层、Esc取消、关闭后焦点回到触发按钮；微信使用等价的可访问标签和可操作顺序。

## 7. 状态切换的视觉反馈

| 规则 ID | 操作与判断 | UI结果 |
|---|---|---|
| ST-01 | 同上下文切换2D／3D | 保留有效座位、楼层、3D模式及每层地图视口，只替换画布与专属工具 |
| ST-02 | 切到不同楼层 | 清空跨层位置；显示目标层已存视口；3D模式保留，需位置时出现选择引导 |
| ST-03 | 确认新位置 | 替换旧位置，同步其楼层、摘要和2D高亮，保持3D模式 |
| ST-04 | 切场次且1F布局版本相同 | 座位仍有效则保留，顶部场次更新，视口保持；A／B即此情形 |
| ST-05 | 1F版本变化或缺失 | 清空原1F位置；变化时提示「座位布局已更新，请重新选择」；缺失时展示「该场次暂未配置一楼座位图」，不复用旧图 |
| ST-06 | 同馆切场次且2F固定版本相同 | 原2F位置仍有效则保留，当前楼层与模式保持 |
| ST-07 | 2F固定版本变化 | 清空旧2F位置，新图复位；不按相同排座号映射 |
| ST-08 | 未来扩展后切换不同场馆 | 清空旧位置、场次与视口；载入目标可用默认状态，回到2D／总览；首版不展示测试馆 |
| ST-09 | 取消浮层或确认当前场馆／场次 | 已确认状态、位置、模式与视口不变；不出现更新提示 |
| ST-10 | 复位地图 | 仅复位当前层视口，选择与底部摘要保持 |
| ST-11 | 清除位置 | 高亮与摘要同时清空，保留场馆、场次、楼层、视图与模式 |
| ST-12 | 数据失败或快速切换 | 保留原已确认上下文，错误提示和重试不冒充切换成功；忽略过期响应，成功后一次更新标题、地图和位置 |

短暂反馈只用于解释变化，不用连续弹窗打断切换。地图选择反馈约120–180ms，浮层约200–250ms；尊重减少动态效果设置。
